# أذكار الصباح والمساء

تطبيق ويب شخصي لمتابعة أذكار الصباح والمساء، بعدّاد لكل ذكر وحفظ تلقائي للتقدم في المتصفح. المشروع مخصص لجهاز واحد، ولا يوجد تسجيل دخول ولا مزامنة بين الأجهزة.

## الميزات

- **الأقسام**: ١٦ ذكراً في الصباح، و١٨ في المساء، و١٠ أذكار نوم مكمّلة تُعرض في نهاية المساء.
- **عدّاد لكل ذكر**: زر واحد يزيد العدد حتى يكتمل، مع شريط تقدم للقسم.
- **أذكار النوم المكمّلة**: لها عدّادها وشريط تقدمها، ولا تُحتسب في اكتمال المساء ولا في «اليوم كامل» ولا في السلسلة. إكمالها كلها — حتى لو لم تكتمل بقية أذكار المساء — يحوّل نقطة المساء في تقويم ذلك اليوم إلى ذهبية.
- **عدّاد كبير**: نافذة للعدّ بضغطات كبيرة للأذكار المتكررة، مع تأكيد قبل إعادة العدّ.
- **اختيار تلقائي للقسم**: الصباح من ٠٤:٠٠ إلى ١٥:٠٠، والمساء فيما عدا ذلك.
- **حفظ يومي**: يُخزَّن التقدم تحت تاريخ اليوم، ويُحتفظ بآخر ٦٠ يوماً.
- **السلسلة والملخص**: السلسلة الحالية وأفضلها، وملخص آخر ٧ أيام (أيام كاملة، صباح، مساء).
- **تقويم شهري**: نقاط لكل يوم توضح اكتمال الصباح والمساء، وتفصيل عند اختيار اليوم.
- **الوقت المتبقي**: يظهر تحت وصف الوقت، ويتحدث كل ٣٠ ثانية.
- **زر «التالي»**: يعرض عدد الأذكار المتبقية وينتقل لأول ذكر غير مكتمل ويبرزه.
- **عنوان التبويب**: يعرض عدد الأذكار المتبقية في القسم النشط، ويصبح ✓ عند الاكتمال.
- **السحب الأفقي**: يساراً إلى المساء، ويميناً إلى الصباح.
- **التراجع**: شريط سفلي لمدة ٥ ثوانٍ يعيد آخر خطوة فقط، مع بقاء زر «إعادة» لكل ذكر.
- **حجم الخط**: أربعة مستويات لنصوص الأذكار فقط.
- **الألوان**: تلقائي يتبع القسم النشط، أو حسب الوقت، أو صباح/مساء بشكل يدوي ثابت.
- **نسخ احتياطي JSON**: تصدير واستيراد مع معاينة وخياري الدمج أو الاستبدال.
- **تصدير CSV**: ملخص يومي لفروق الصباح والمساء، مناسب لجداول البيانات.
- **تذكير بالنسخ الاحتياطي**: ينبّهك إذا مرّ ١٤ يوماً دون تصدير نسخة.
- **إتاحة**: واجهة عربية RTL، تسميات لقارئ الشاشة، وإعادة تعيين اليوم بخطوتين.

## التشغيل

لا يحتاج المشروع إلى تثبيت أو بناء:

1. افتح `index.html` مباشرة في متصفح حديث (Chrome أو Edge أو Firefox أو Safari). الملفات الأربعة تُحمَّل من نفس المجلد، فلا تفصل `index.html` عن `styles.css` و`app.js` و`theme-init.js`.
2. إن قيّد متصفحك التخزين عند فتح الملف مباشرة، شغّله عبر خادم محلي اختياري:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

> التقدم محفوظ في `localStorage` الخاص بالمتصفح. مسح بيانات الموقع أو استخدام وضع التصفح الخاص يعني فقدان التقدم، لذا صدّر نسخة احتياطية بين فترة وأخرى.

## البيانات والتخزين

يُفصل التقدم عن الإعدادات في مفتاحين مستقلين:

| المفتاح | المحتوى |
|---|---|
| `douaa-tracker.v1` | التقدم اليومي |
| `douaa-tracker.settings.v1` | حجم الخط والثيم وتاريخ آخر تصدير |

شكل بيانات التقدم:

```json
{
  "days": {
    "2026-10-31": {
      "morning": {
        "morning-0": { "count": 1, "done": true }
      },
      "evening": {},
      "sleep": {
        "sleep-0": { "count": 1, "done": true }
      }
    }
  }
}
```

- مفاتيح الأذكار تعتمد على ترتيبها: `morning-0`، `morning-1`، `evening-0`، `sleep-0`، وهكذا.
- أذكار النوم محفوظة في مجموعة `sleep` مستقلة، ولا تدخل في حساب اكتمال المساء.
- **يوم كامل** = اكتمال قسم الصباح وقسم المساء معاً. التقويم يميز اليوم الجزئي (قسم واحد) عن اليوم الكامل. أذكار النوم لا تشترط لاكتمال اليوم.
- تُحذف الأيام الأقدم من ٦٠ يوماً تلقائياً عند الحفظ، ولذلك يقتصر التقويم على الشهر الحالي والأشهر التي تحتوي بيانات محفوظة.
- البيانات محلية على هذا الجهاز فقط، ولا تُرسل إلى أي خادم.
- عند التحميل تُنظَّف البيانات في الذاكرة: تُقصّ العدادات، ويُعاد حساب الاكتمال، وتُهمل التواريخ غير الصالحة أو المستقبلية والمفاتيح غير المعروفة. يُنظَّف التخزين نفسه عند الحفظ التالي.

## النسخ الاحتياطي

- **التصدير**: من قسم «الإعدادات» ← «تصدير نسخة». يُنزّل ملفاً باسم `douaa-tracker-YYYY-MM-DD.json` يحتوي التقدم والإعدادات.
- **الاستيراد**: «استيراد نسخة» ← اختر الملف ← راجع المعاينة ← اختر «دمج مع الحالي» أو «استبدال الكل».
- **الدمج**: يحتفظ بالعدد الأكبر لكل ذكر (ولا يخفض أي عدّاد)، ويضم الأيام الجديدة، ويحتسب الذكر بلا عدد محدد مكتملاً إذا كان مكتملاً في أي من النسختين. لا يغيّر إعداداتك الحالية.
- **الاستبدال**: يمسح التقدم الحالي ويأخذ تقدم الملف وإعداداته بعد التأكيد.
- تُرفض الملفات الأكبر من ٢ ميجابايت، والتواريخ غير الصالحة، والتواريخ المستقبلية.
- تُقصّ العدادات على الحد الأقصى لكل ذكر، ويُعاد حساب الاكتمال، ويُحتفظ بآخر ٦٠ يوماً فقط.
- **تذكير**: عند مرور ١٤ يوماً دون تصدير نسخة، يظهر تنبيه في الإعدادات.

### تصدير CSV

- زر «تصدير CSV» ينزّل ملخصاً يومياً باسم `douaa-tracker-YYYY-MM-DD.csv`.
- الأعمدة: التاريخ، اكتمال الصباح، عدد أذكار الصباح المكتملة، اكتمال المساء، عدد أذكار المساء المكتملة، أذكار النوم المكتملة، اكتمال اليوم.
- يُكتب الملف بترميز UTF-8 مع BOM، ويفتح في Excel بالعربية دون إعدادات إضافية.
- أذكار النوم تُصدَّر في عمود مستقل، ولا تؤثر في عمود «اكتمل اليوم».
- التواريخ في CSV ميلادية بصيغة `YYYY-MM-DD`، والأرقام لاتينية لتسهيل الفرز والحساب.

## الإعدادات

- **حجم نص الأذكار**: صغير، متوسط، كبير، كبير جداً.
- **الألوان**:
  - `تلقائي`: يتبع القسم النشط (صباح أو مساء).
  - `حسب الوقت`: يتبع الساعة نفسها بنفس نافذتي الصباح والمساء، ويتحدث تلقائياً.
  - `صباح` أو `مساء`: يثبّت اللوحة حتى عند تبديل القسم. لا يؤثر الثيم على تحديد القسم النشط.
- الإعدادات محفوظة لكل جهاز على حدة، ويُضاف إليها تاريخ آخر تصدير لتذكير النسخ الاحتياطي.

## البنية

```text
douaa-tracker/
├── index.html        # البنية والمحتوى فقط
├── styles.css        # كل التنسيقات
├── theme-init.js     # تطبيق الثيم وحجم الخط قبل الرسم
├── app.js            # منطق التطبيق كامل
├── tests/
│   ├── check.js      # فحص الصياغة والبنية والمعرّفات
│   └── sim.js        # محاكاة DOM واختبار السلوك
├── README.md
├── .gitignore
└── .gitattributes
```

لا توجد مكتبات خارجية ولا خطوة بناء. تُحمَّل الملفات الأربعة معاً، لذا أبقِها في مجلد واحد. الخطوط تُحمَّل من Google Fonts مع بدائل محلية. اختبارات `tests/` تحتاج Node.js فقط، ولا تعمل داخل المتصفح.

## الاختبارات

```bash
node tests/check.js
node tests/sim.js
```

- `tests/check.js`: يفحص صياغة `app.js` و`theme-init.js`، وتوازن أقواس CSS، وخلوّ HTML من السكربتات والأنماط المضمّنة، ووجود كل معرّف يستخدمه التطبيق أو تحاكيه الاختبارات.
- `tests/sim.js`: يبني DOM مصغّراً ويشغّل `theme-init.js` ثم `app.js`، ثم يختبر العدّ والتبويبات والثيمات والتقويم والسلسلة والاستيراد والدمج والتصدير والعدّاد والنقطة الذهبية لأذكار النوم. ينتهي بملخص عدد الفحوصات الناجحة والفاشلة، ويفشل الأمر عند أي خطأ.

## الخصوصية

- لا حسابات، ولا تحليلات، ولا خادم، ولا إرسال لبيانات التقدم.
- كل البيانات في `localStorage` على جهازك.
- الخطوط تُطلب من `fonts.googleapis.com` و`fonts.gstatic.com`. لفصل كامل عن الشبكة، استبدل رابط الخطوط بملفات محلية.

## ملاحظات للتطوير

- وزّع التعديلات على الملف المناسب: البنية في `index.html`، والتنسيق في `styles.css`، والمنطق في `app.js`، وتهيئة الثيم قبل الرسم في `theme-init.js`. لا يوجد `npm install` ولا bundler.
- شغّل `node tests/check.js` و`node tests/sim.js` بعد أي تعديل قبل الكوميت.
- مفاتيح التقدم مرتبطة بترتيب الأذكار. إعادة الترتيب أو الإدراج في المنتصف تُغيّر ارتباط التقدم لذلك اليوم، فالأفضل إضافة الأذكار في النهاية أو ترقية مفتاح التخزين. أذكار النوم في مجموعة `sleep` مستقلة، فلا تؤثر إضافتها على مفاتيح المساء.
- الثوابت المهمة داخل `app.js`: `STORAGE_KEY`، `SETTINGS_KEY`، `KEEP_DAYS`، `PERIOD_WINDOWS`، `BACKUP_REMINDER_DAYS`، و`MAX_BACKUP_BYTES`.
- `theme-init.js` يطبّق الثيم وحجم الخط قبل الرسم لمنع وميض الألوان؛ يجب أن يبقى متوافقاً مع `SETTINGS_KEY` و`PERIOD_WINDOWS`. الثيم `time` يعتمد فيه هذا السكربت على الساعة مثل `auto`، ثم يُصحَّح بعد التحميل.
- رسائل الكوميت تتبع [Conventional Commits](https://www.conventionalcommits.org/): `feat:`، `fix:`، `docs:`، `chore:`.
